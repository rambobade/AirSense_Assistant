AirSense

Air quality monitoring and AQI assistant for the Mumbai region.

About the project

AirSense is a final-year project that collects air-quality readings from monitoring stations around Mumbai and turns them into easy-to-read AQI information. It calculates the Indian National AQI using CPCB-style breakpoints, estimates short-term AQI changes, and maps pollution hotspots using GIS interpolation. This page is the project's web front end, and the assistant at the bottom answers questions using the AirSense Dialogflow agent.

Project information

Region Mumbai, India
Pollutants PM2.5, PM10, NO₂, SO₂, CO, O₃
AQI standard Indian National AQI (CPCB)
Forecast model Random Forest
Data sources OpenAQ and Open-Meteo
Course B.E. Information Technology, Major Project-I

AQI categories

Air quality is reported using the Indian National AQI scale.

  • Good 0 - 50
  • Satisfactory 51 - 100
  • Moderate 101 - 200
  • Poor 201 - 300
  • Very Poor 301 - 400
  • Severe 401 - 500
